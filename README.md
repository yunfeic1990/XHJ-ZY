## 使用方法

1. 打开 Shadowrocket，进入底部 **配置** 标签页
2. 点击右上角 **＋**
3. 粘贴上面的配置直链，点击下载
4. 点击下载好的配置，选择 **使用配置**
5. 在首页添加你自己的节点或订阅

## 更新配置

在 **配置** 页面，点击该配置右侧的 ⓘ，选择 **更新** 即可获取最新版本。
